### 2. [TK Nusantara — Admissions Analytics & Sliding-Scale Tuition Subsidy Modeling](https://github.com/RifasaHadiarto/tk-nusantara-admissions-analytics)
> **Stack:** Tableau Public • Advanced SQL (Window Functions, CTEs) • Python (`openpyxl`) • UU PDP / PII Compliance  
> **Domain:** Education Operations & Financial Aid Optimization  
* Processed 285 raw Google Form admissions, resolving registration duplicates down to 104 verified student profiles while strictly enforcing data privacy (anonymizing PII / NIK).
* Engineered a multi-tier sliding-scale tuition subsidy query in SQL using `ROW_NUMBER() OVER (PARTITION BY ...)` and conditional fee brackets.
* Built an interactive 4-component Tableau dashboard analyzing class preferences, regional dispersion, and parental income distributions.
* 🔗 **[Explore Live Tableau Dashboard](https://public.tableau.com/)** • **[GitHub Repository](https://github.com/RifasaHadiarto/tk-nusantara-admissions-analytics)**

### 3. [YouTube Comments Sentiment Analysis & Indonesian NLP Pipeline](https://github.com/RifasaHadiarto/youtube-sentiment-analysis-indonesian)
> **Stack:** Python (Google Colab) • YouTube Data API v3 • RegEx Slang Normalization • Seaborn  
> **Domain:** Social Listening & Brand Sentiment  
* Automated extraction of YouTube video comments using Google Cloud API pagination handling.
* Constructed a custom Indonesian NLP pipeline: regex emoji filtering, 50+ informal/slang token normalizer (e.g. *bgt $\rightarrow$ banget*), and negation-aware scoring (*"tidak bagus"* marked negative despite positive word presence).
* Visualized sentiment distribution and keyword frequency via Matplotlib, Seaborn, and WordCloud.
* 🔗 **[Open in Google Colab](https://colab.research.google.com/drive/1H2cyYVkeH3tRTUXjHypsI-PYQoJedkf3)** • **[GitHub Repository](https://github.com/RifasaHadiarto/youtube-sentiment-analysis-indonesian)**
